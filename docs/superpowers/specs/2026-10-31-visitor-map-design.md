# 访客地图设计
用户已确认：仪表盘增加可缩放、拖动的世界地图，默认中国视角；今日/7天/30天，PV和独立IP切换。城市聚合圆点及排名，未知位置单列；历史PV无位置不伪造补全。
采用本地世界矢量底图和DB-IP Lite离线城市定位，支持国际IP，页面署名。既有百度/高德接口只返回文本，逐访问请求有延迟和配额，因此本功能独立离线定位；不改变既有定位接口。
数据库保存按日、散列IP的计数与近似位置；不存原始IP。区间UV通过COUNT DISTINCT散列IP计算，不累加每日UV。只信任来自回环反代的X-Real-IP。最多保留90天，页面仅提供30天。位置不是GPS，未知单列。
沿用后台鉴权。地图不展示IP或任何密钥。本次实现并验证，延续本会话发布流程同步Git与服务器。
