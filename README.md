# bcBlog

一个前后端分离的个人博客项目，前台面向游客开放阅读，后台供管理员发布内容、管理站点。支持二次元风格主题、多种氛围组件，并逐步向论坛方向扩展。

## 技术栈

- 后端：Spring Boot 2.6.13 / Java 8 / MyBatis-Plus / Sa-Token / MySQL 8
- 前端：Vue 3 / Vite / Element Plus / Pinia / Axios / wangEditor

## 现有功能

### 前台

- 首页文章卡片瀑布流 + 时间线布局
- 首页中段最新文章轮播、音乐播放器与歌词栏
- 文章详情、归档、搜索，文章详情展示封面
- Gitalk 评论（基于 GitHub Issues），首页最近评论下拉展示
- 流光忆庭照片墙、智库资源区
- 白天樱粉 / 夜晚星空主题，可自由切换
- 樱花、星空粒子、点击涟漪等氛围组件
- 网易云音乐播放器、一言、Live2D 看板娘
- 实时天气卡片（自动定位 + 北京时间）
- 站点公告栏、阅读进度、图片灯箱、代码高亮与复制、回到顶部
- 页脚显示系统稳定运行时间与北京时间
- 用户注册 / 登录（邮箱即账号）、邮箱验证码、用户中心
- 用户等级与经验、积分、每日签到、邀请码
- 原生评论系统（可后台切换到 Gitalk），未登录可看、登录后可评论
- 评论与文章编辑支持表情包
- 智库资源详情页，前往资源消耗积分，解锁后不重复扣除
- 沙盒世界：AI 角色在地图上的自动生活，含地图、档案、状态与行动时间线
- 沙盒旅人低语：登录用户消耗积分给角色留言，角色下次行动会参考
- 沙盒金币：登录用户可用积分为角色贡献金币，角色会在日常活动中赚取或花掉
- 沙盒旅人集市：AI 定时刷新的商品，登录用户用积分买下赠送给角色（礼物会出现在角色的下一次行动里）
- 沙盒旅人委托板：角色自己看委托、接取、推进进度、领金币与物品奖励；完成的委托留在角色档案里
- 沙盒旅人纪闻：当天世界大事件的新闻栏，角色行动会参考（后台可手写）

### 后台

- 管理员登录（图形验证码、失败锁定、IP 频率限制）
- 仪表盘：文章数据、访问量统计、系统性能监控、系统信息与依赖版本
- 文章 / 分类 / 标签 / 评论管理
- 富文本文章发布与编辑，本地图片上传
- AI 一键写文章，支持多个 AI 服务商切换
- 分类 + 标签管理，支持多级分类
- 站点设置（名称、Logo、备案、SEO、首页标语）
- 背景壁纸管理（图片 / 视频，前后台可独立设置，后台背景透明度可调）
- 看板娘模型管理、网易云歌单管理、站点公告管理
- 流光忆庭照片管理、智库资源管理
- 管理员分级（超级管理员 / 一级 / 二级）与一二级菜单授权
- 登录日志查看、清空与 IP 位置查询
- 第三方接口配置（天气、一言、敏感词、IP 定位、ACG 随机封面、Gitalk 评论）
- 用户管理：普通用户列表、封禁、积分发放（单个或全站）
- 等级配置、邀请码管理、表情包管理
- QQ 邮箱配置与邮件模板管理（多套模板切换、预览、测试发送）
- 评论系统切换（Gitalk / 原生评论）、Gitalk 评论后台管理
- 数据清理：按天自动清理登录日志、访问统计、签到与积分流水，执行时间与保留天数可配
- 沙盒世界管理：地图背景、地名与坐标（可拖动标记）、世界观设定、运行参数（开关 / 间隔 / 夜间静默 / 每日上限 / 低语积分）
- 沙盒角色管理：人设、立绘、绑定任意 AI 服务商与模型、启停自动行动、一键立即执行
- 沙盒日志：行动记录与旅人低语查看、删除
- 沙盒集市 / 委托板 / 纪闻：AI 生成与手写、刷新间隔与当天首次时间可配、可立即执行一次

## 快速开始

1. 准备数据库（详见 `docs/sql/README.md`）：
   - 全新安装：执行 `docs/sql/bc_blog_full.sql`，创建 `bc_blog` 库中的全部 38 张表。
   - 已有旧库升级：执行 `docs/sql/upgrade_20260916_batch.sql`（已合并 001~033 全部改动），脚本幂等、可重复执行，不会清空数据。
2. 修改 `src/main/resources/application.yml` 中的数据库账号密码。
3. 启动后端：运行 `BcBlogApplication`。
4. 启动前端：

```bash
cd frontend
npm install
npm run dev
```

5. 访问前台 http://localhost:5173，后台 http://localhost:5173/login。

首次启动后端会自动创建默认管理员：

- 用户名：`admin`
- 密码：`Admin@123456`

登录后请尽快在后台右上角修改密码。
